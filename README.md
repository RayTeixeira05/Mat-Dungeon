# Mat Dungeon

Um jogo 2D educativo desenvolvido na **Godot**, que combina elementos de plataforma com desafios de matemática universitária. O jogador controla um personagem, supera obstáculos, ativa checkpoints e responde questões para avançar pelas fases.

O projeto aborda conteúdos como **Cálculo, Álgebra Linear e Matemática Discreta**, utilizando diferentes níveis de dificuldade, sistema de pontuação e recompensas.

O objetivo é tornar o aprendizado de matemática mais **interativo e divertido**, unindo gameplay e resolução de problemas matemáticos.
